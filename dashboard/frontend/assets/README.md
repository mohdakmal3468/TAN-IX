# Static Assets Directory
`dashboard/frontend/assets/`

This folder stores static visual assets used in the TAN-IX Streamlit command center:
- **`logo.png`**: State Emblem & TAN-IX branding mark.
- **`cluster_icons/`**: SVGs/PNGs for Kanpur (Tannery), Unnao (Leather Complex), Agra (Footwear), Noida (Apparel).
- **`maps/`**: UP expressways vector geo-assets and corridor schematics.
- **`badges/`**: ODOP certification marks and NGT green compliance indicators.
